# Bot 中文库实现计划

## 目标

完整翻译 Grok Bot Marketplace 当前公开的每个 Bot 详情，让用户用中文理解角色、工作规则、技能、例行任务和应用集成。网站以阅读详情为核心，目录用于查找。保留作者、原名、来源及英文对照。

## 架构

- Python 标准库采集公开页面，并解析页面内嵌的模板结构；保留英文源数据。
- 每个模板独立保存中文 JSON，原文与译文按字段和条目 ID 对齐。
- 无依赖的 HTML、CSS 和 JavaScript 静态阅读应用，使用 Node 标准库启动本地服务器。
- 中文名称、用途、分类、作者和全文搜索；详情分工作规则、技能、例行任务、集成；支持中英对照、复制、Markdown 下载及深链接。
- 空字段明确显示原站未提供，不补写或虚构模板功能。网站不执行 Bot，不代替 Grok 导入运行。

## 阅读设计

按用户指定的 apple-design 技能和暗色极客风更新。参考 `reading-concept-dark.png`：石墨黑背景、浅灰正文、青色选中态、半透明工具栏、即时按压反馈及减少动态效果支持。原亮色图仅作为历史概念保留。左侧模板目录，中间详情正文，宽屏右侧条目目录。手机使用可收起目录。正文行高 1.85，正文阅读宽度适中。实际名称与内容严格以原文为准，概念图中的示意文字不作为内容来源。

## 验证

1. 目录与详情数量一致，每个模板必须有中文译文。
2. 四类详情数组与英文原文数量、ID 一致，无未解析的引用及空译文。
3. 保留操作限制、时间频率、标识符和外部服务名称。
4. 浏览器验证搜索、分类、详情切换、中英对照、复制、下载、深链接及手机布局。
5. 完整中文模板同时输出为 Markdown，方便脱离网站使用。
